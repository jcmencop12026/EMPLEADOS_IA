# Activos de identidad EIAAX

Coloque aquí los activos oficiales cuando estén disponibles. El sistema los resuelve por **identificador**, sin rutas hardcodeadas por pantalla.

## Convención de nombres

| Identificador | Archivo sugerido | Uso |
|---------------|------------------|-----|
| `eiaax-hero` | `eiaax-hero.svg` o `.png` | Login, landing |
| `eiaax-corporativo` | `eiaax-corporativo.svg` | Sidebar expandido |
| `ex-08` | `ex-08.svg` | Sidebar colapsado |
| `ex-micro` | `ex-micro.svg` | Favicon, espacios mínimos |

Formatos admitidos: `.svg`, `.png`, `.webp` (se prueba en ese orden).

Si el archivo no existe, la UI usa **marcas tipográficas** definidas en `BrandMark` (sin inventar logo).
