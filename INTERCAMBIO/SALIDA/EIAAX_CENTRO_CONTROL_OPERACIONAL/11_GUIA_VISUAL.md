# 11 — Guía visual

## Ruta

`/` o `/centro-control` — **Centro de Control operacional**

## Pestañas

1. **Resumen operacional** — KPIs panorama + indicadores + atención top
2. **Empleados IA** — fuerza laboral con estados lifecycle
3. **Ejecuciones** — resumen y lista con drill-down
4. **Requiere atención** — bandeja priorizada
5. **Capacidad y consumo** — MB-07 + FinOps estimado/real
6. **Aprobaciones** — operaciones + fábrica
7. **Salud de servicios** — plataforma, continuidad, proveedores
8. **Valor** — consolidado ejecutivo (separado de operación)

## UX

- Español, compacto empresarial
- Última actualización visible
- Sin JSON crudo, sin botones muertos
- Enlaces a evidencia (empleado, ejecución, FinOps)
