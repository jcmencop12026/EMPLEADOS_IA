## Cómo ver el resultado

1. Iniciar backend y frontend (`backend` + `frontend/npm run dev`).
2. Login como admin.
3. Menú **Análisis y control → Evaluaciones EIAAX**.
4. Crear expediente → completar información → **Ejecutar evaluación preliminar**.
5. Pestañas: Análisis, Impacto, Oportunidades, Vista Entidad, Trazabilidad.
6. Panel lateral **Preguntar a EIAAX**.
