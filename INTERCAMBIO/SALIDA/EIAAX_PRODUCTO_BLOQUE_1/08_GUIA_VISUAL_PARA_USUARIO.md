# 08 — Guía visual para usuario

## Acceso

1. Inicie sesión en EIAAX (pantalla de login muestra nombre y descriptor del producto).
2. En el menú lateral, sección **Análisis y control**, seleccione **Evaluaciones EIAAX**.

## Crear una evaluación

1. Pulse **Nueva evaluación**.
2. Complete: título, entidad, área/proceso, nivel (Preliminar recomendado para empezar).
3. Describa el **problema** y el **objetivo**.
4. Pulse **Crear expediente**.

## Consola del expediente

### Encabezado ejecutivo
Muestra: Entidad, Estado, Información %, Confianza, Oportunidades, Valor potencial.

### Pestañas

| Pestaña | Uso |
|---------|-----|
| **Resumen** | Problema, objetivo, ejecutar evaluación preliminar |
| **Información** | Completar requisitos adaptativos; estados en color |
| **Análisis EIAAX** | Hallazgos, confianza, marcar visible para entidad, crear oportunidad |
| **Impacto e Indicadores** | ANTES / PROYECTADO / REAL |
| **Oportunidades** | Enlaces al Centro de oportunidades |
| **Vista Entidad** | Lo que vería el cliente (solo elementos marcados visibles) |
| **Trazabilidad** | Historial y cambios de visibilidad |

## Preguntar a EIAAX

Botón superior derecho abre panel lateral con acciones sugeridas. Si no hay proveedor IA configurado, verá instrucciones en español (no respuestas inventadas).

## Buenas prácticas

- Complete al menos contexto y problema antes de evaluar.
- Distinga **Problema original** de oportunidades adicionales.
- Marque visible solo hallazgos validados para la entidad.
- Use **Vista Entidad** antes de compartir resultados.
